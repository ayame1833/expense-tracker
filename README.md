expense-tracker app (2 participants)

1. For whom?
The people who live with someone or go trip with someone.

2. Why I developed this app?

In our household, we split all expenses.
In response to my husband's request for a expense-tracker app, I developed as following.


3.How to use the program

<1>. We can set two participants.
<2>. We can register  [Add, Transfer, List, Status, Delete, Exit] in the tracker.
     Add - Add [Payer,Pay-Date,Usage, Amount:exchanged] in list.
           Each Amounts[AUD, USD, EUR, CNY, INR] are exchanged and registered as JPY in the tracker for Transfer.
     Status - Check which person need to pay to another.
     Transfer - Pay amount to another person. 
     List - Show the current list and sum total in each items[food,rent,transger,else]
     Delete- We can delete lines when you mistake your registration.
     Exit - to exit from this app!
 ※All tracker is recorded in JPY for our transfer.If you would like to record your currencies, please change <add> command.
